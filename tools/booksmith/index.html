        How to use

        1. Add a book. Click Add a book below the stack.
        2. Arrange your books. Drag them into the order you want, then choose Priority, Blend or Equal. On touchscreens, drag the colored strip or the share directly, or hold briefly before dragging elsewhere on the row. You can also focus a book and use the up and down arrow keys.
        3. Edit a line. Select a book, shown with a dark outline. Play moves on the board or use the opening search beneath that book to add its line.
        4. Adjust move weights. Use the sliders to change how often moves are chosen. If Priority names another book above the moves, select that book to edit its weights.
        5. Export your book. Click Export .bin to download the merged result.
        6. Use it in A.C.A.S. Load the file in the Opening Book setting in the A.C.A.S GUI. For one book arrow, set that profile's Funneling to Books only.

        More details

        Merging books
        • Priority: the top visible book with moves for a position decides. Lower books fill the gaps.
        • Blend: every visible book contributes, with more weight given to higher books.
        • Equal: every visible book contributes with equal weight.

        Arrows, percentages and move bars show the merged result. Colors identify the books contributing to each move.

        In Priority, non-empty visible books keep a lightly tinted track, even when a higher book controls their positions.

        Add all continuations

        Click Add all continuations below the moves to add every opening catalogue continuation from the current position to the selected book, not just the next moves.

        At the starting position, this adds the whole catalogue. After 1.e4 c5, it adds Sicilian continuations. New moves are weighted by how many catalogue lines use them, not game popularity. Existing moves and weights stay unchanged.

        Build a book from games
        1. Click Add a book, then Import books and choose a .pgn file, such as one downloaded with Export Matches.
        2. Select a player, or All players. Choose a color and set Depth and Min. games.
        3. Click Build to add the resulting book to the stack.

        Depth sets how many moves deep to go. Min. games keeps moves played in at least that many games. Keep it low for small imports, since games branch out quickly.

        If a game contains an unreadable move, only valid moves before it are kept and a warning stays visible. Stopping at your chosen depth is normal and does not count as an incomplete import.

        Choose a preset or import a book

        Click Add a book, choose a preset and click Add. Starters keep lines short, repertoires cover opening families, and personalities favor a particular style. Each preset becomes an editable book.

        To use an existing opening book, click Add a book, then Import books and choose a .bin or .epd file. You can import multiple books and arrange them in the stack.

        Weights, visibility and navigation

        Sliders set relative weights, not percentages. A higher weight makes a move more likely, not guaranteed. In Priority, select the book named in the notice to edit the moves it controls. Other books keep their weights and fill gaps.

        Moves with a 0% chance stay in the list for editing, but do not draw arrows on the board.

        Hide a book with its eye button to exclude it from the result. Its weights stay saved, and its moves may still appear if another visible book includes them. Show the book again to edit its weights.

        Click a move's name to follow it. Use the board buttons to go back, forward, return to the start or flip the board. Press Ctrl+Z to undo and Ctrl+Y to redo.

        Back up and restore your workspace

        Click Backup to download a workspace .json containing all books, names, colors, order, visibility, the selected book, merge mode and board orientation.

        Click Restore and choose a backup to replace the current workspace after confirmation. You can undo the restore. Backups do not include the board's current line or undo history.

        Use Export .bin instead when you want an opening book for a chess engine.
