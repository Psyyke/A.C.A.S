Export Matches

Download public Chess.com or Lichess games into one PGN file.

Download Tool (HTML)
  1. Open the downloaded HTML file in your browser.
  2. Choose a chess site and enter the player's username.
  3. Collect games and save the PGN.
  4. Import the PGN into DoppelMaia.

Export chess games as PGN

Use a Chess.com or Lichess username to download public, completed standard chess games. Both rated and casual games are included. More options lets you choose UTC dates, a game limit and all categories or just bullet, blitz or rapid.

Requests run one at a time and wait when the service asks for a break. You can stop early and save a clearly marked partial file. The status shows progress, skipped games and any errors.

Import the PGN into DoppelMaia to personalize Maia chess weights, or use it with another chess analysis tool. DoppelMaia accepts up to 100 MiB across all files selected together. Choose fewer games or a shorter date range if your collection is too large.

Can I export any player's games?

You can request games made available by the site's public API. Private or restricted games, ongoing games and nonstandard variants are not included. Availability depends on the provider.

What if my browser blocks collection?

Open the downloaded file in a current desktop browser. Check the status message for the error. Do not disable browser security or supply account tokens.
