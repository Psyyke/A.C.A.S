Modified for A.C.A.S on 2026-11-09. Changes include the browser UCI bridge,
WebAssembly build configuration, browser ONNX inference backend, conversion
memory handling and optional float16 weight storage. These are local changes,
not an unmodified official Lc0 release.

build.mjs contains the checked source modifications and pins the upstream
revision. It checks out upstream submodules and builds the modified source.
The browser bridge and converter additions are supplied as source files here.
package-lock.json pins the JavaScript dependencies. dist/build-info.json
identifies the runtime versions and memory limit.

Publication requirements:
Publish these source files, exact patches, build instructions and notices
alongside the corresponding dist binaries in the same GitHub commit/release.

Keep that source revision accessible for recipients of the matching binaries.
For a release, link to its immutable GitHub source revision rather than relying
only on the moving main branch. Review source availability for upstream and
build dependencies as part of release preparation.
