The NNUE networks, personality text files and Polyglot books in dist/assets
are copied unchanged from the pinned upstream tree.

A.C.A.S browser modifications are supplied in browser.go, worker.js,
personality.js, runtime-worker.js, ../text-files.js and build.mjs.
They adapt input, resource access and search
scheduling to workers, select scalar NNUE kernels, build both network widths,
restore state across runtime changes, clear style-dependent caches, bound
browser memory/thread options, accept inline personality contents and
implement UCI root-move restrictions.

Corresponding upstream source is supplied as dist/rodent-v-source.zip.
The browser source and build instructions must accompany the distribution.

https://github.com/Psyyke/A.C.A.S/tree/main/app/assets/engines/rodent-v
